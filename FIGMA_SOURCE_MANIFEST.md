# Figma Source Manifest

Source: https://www.figma.com/make/JXmpEtx8a56wjw6EXdFvyP/Rebrand-to-CYNX

The Figma Make file exposes these major source areas:

- `src/app/App.tsx`
- Service components for AI consulting, data strategy, digital due diligence,
  buy-or-build analysis, AI discovery, software solution design, UX design,
  data transformation, AI software, AI agents, model training, integrations,
  web apps, mobile apps, portals, CRM/ERP, systems integration, and
  modernization
- Shared components for tech stack tabs, cursor spotlight, contact modal,
  about page, and image fallback
- shadcn/ui primitives generated by Figma Make
- Tailwind and theme CSS
- Figma-generated PNG assets and Unsplash images

This repository keeps the design content and page flows, but consolidates the
generated component surface into a maintainable Vite React structure:

- `src/App.tsx` contains the page shell, navigation, modals, service views, and
  interaction logic.
- `src/cynx-data.ts` contains the full typed CYNX service, case study, tech
  stack, and partner content.
- `src/styles.css` contains the responsive CYNX visual system.
- `server/index.ts` provides the Node.js contact API and serves Vite in
  development or `dist` in production.
